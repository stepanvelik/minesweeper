# Сапёр HD — гонки по Wi-Fi

Классический «Сапёр» на Python + pygame: тёмная и светлая темы, уровни сложности,
очки, магазин скинов, подсказки — и сетевая гонка по Wi-Fi на одинаковой карте.

## Запуск

Нужен Python 3.9+. Зависимость одна — `pygame` (см. `requirements.txt`, проверено:
ставится и импортируется, `pygame 2.6.1`).

```bash
python3 -m pip install -r requirements.txt
python3 minesweeper.py
```

На Windows вместо `python3` пиши `py`:

```bash
py -m pip install -r requirements.txt
py minesweeper.py
```

> Если пишет «имя pip3 не распознано» (или `pip: command not found`) —
> это нормально: команды `pip` / `pip3` просто нет в PATH.
> Всегда используй форму `python -m pip` (или `py -m pip` на Windows) —
> она работает через сам Python и ничего лишнего не требует.
> На Windows при установке Python с python.org поставь галочку
> «Add python.exe to PATH», на Mac — команды выше работают сразу.

## Управление

| Клавиша / мышь | Действие |
|---|---|
| ЛКМ по клетке | Открыть |
| ЛКМ по цифре / колесо | Открыть всё 3×3 вокруг (кроме флажков) |
| ПКМ | Флажок |
| `1` / `2` / `3` | Подсказки: безопасный ход / найти мину / щит от взрыва |
| `R` | Новая игра |
| `S` | Магазин (уровни, темы, скины) |
| `T` | Светлая / тёмная тема |
| `G` | Wi-Fi гонка |

## Уровни и очки

- EASY 8×8 (+100 очков), NORMAL 10×10 (+250), HARD 14×14 (+600)
- Победа: база уровня минус 25 за каждую подсказку (минимум четверть базы)
- За очки в магазине покупаются скины бомб (Fuse / Classic / Neon)
  и флажков (Wave / Classic / Pirate). Выбор сохраняется автоматически.

## Wi-Fi гонка (кто быстрее — тот выиграл)

Все игроки должны быть в **одной Wi-Fi сети**, игра запущена у каждого.

1. Один игрок жмёт **RACE [G]** → **HOST GAME [H]**.
2. В лобби хост видит свой IP (например `192.168.1.5`) и диктует его друзьям.
3. Остальные вводят этот IP в поле Host IP → **JOIN [J]**.
4. Хост жмёт **START [Space]** — всем раздаётся **одинаковая карта**
   (центр предоткрыт для честного старта).
5. Кто раньше открыл все клетки — победил, взрыв = поражение (DNF).
   Прогресс соперников виден в шапке, в конце — таблица с местами.

Технически: прямое TCP-соединение (порт `50007`), хост — сервер.
Через интернет без настройки роутера не заведётся, только одна локальная сеть.
